# 常见问题

## 两台设备的密钥指纹不一样怎么办？

说明口令不同，或者其中一台在仓库还没有盐值时就抢先创建了自己的盐。

1. 在仓库里确认 `key/salt` 只有一个文件、内容非空。
2. 在所有设备上填**完全相同**的口令（注意首尾空格、全角字符）。
3. 还是不一致：删掉该设备的 `~/.dsh/dsh-sync/state.json`，重启引擎再同步一次。仓库里的数据不动。
4. 如果仓库里的盐值是某台设备误建的，而你已经在旧口令下推过东西：用旧口令导出会话（`dsh-sync export`），用新口令建一个新仓库，再导入。

## 提示「仓库拒绝访问」

- 令牌是否只给了这一个仓库的 **Contents: Read and write**？
- 令牌是否过期？
- 私有仓库的地址应是 `https://github.com/你/仓库.git`，不是网页地址。
- 组织仓库可能需要在令牌上额外授权该组织。

## 提示「连不上仓库」

手机切到后台被系统限流时常见。打开 App 让它在前后台跑一次同步即可；也可以确认网络能访问 GitHub（部分网络需要代理）。

## 同步了但另一台设备看不到

按顺序检查：

1. 面板里的「已推送」在涨吗？不涨说明本地采集没成功。
2. 另一台设备点「立即同步」，「已拉取」在涨吗？
3. 两边指纹一致吗？
4. 会话列表里出现了吗？出现但没导入，通常是那台设备已经有同 id 的会话（不会覆盖，这是故意的）。

## 会不会把我的 API Key 传上去？

不会。消息同步只发对话内容；可选的设置同步会先过白名单，任何仍含 `apiKey`/`token`/`secret` 的文档整份丢弃。见 [SECURITY.md](../SECURITY.md)。

## 仓库会不会越来越大？

会。一条 1400 事件的会话约 0.9 MB。定期 `git gc`，或者按年份分仓库。不建议把同一个仓库用于几十万条消息。

## 能不能同步附件和图片？

目前只记录引用（attachment id），字节不跟着走。需要的话，把附件目录挂到同一个同步盘是更简单的做法。

## Codex 那边怎么用？

装 `dsh-sync-mcp`，在 Codex 的 MCP 配置里指向它。Codex 就能调 `sync_now`、`list_sessions`、`read_session`。它读到的是同一段对话的 Markdown 或 JSON。

## 能不能不用 GitHub？

可以。任何 Git 远端都行（Gitea、GitLab、自建 SSH 仓库），或者把 `backend` 设成 `folder`，指向 Syncthing / iCloud / 坚果云挂载的目录。

## 卸载会删掉我的对话吗？

不会。卸载插件只是不再同步；仓库里的数据和本机的会话都还在。要彻底清除，需要自己删仓库和本机 `~/.dsh/dsh-sync`。
